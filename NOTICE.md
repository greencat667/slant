# Third-party code

- `slant/src/esp_codec_dev/` - Espressif's esp_codec_dev component, Apache License 2.0 (see the `LICENSE` file in that folder).
- `slant/src/display/`, `slant/src/power/`, `slant/src/codec_board/` - hardware driver code adapted from Waveshare's official example code for the ESP32-S3-ePaper-1.54 board (https://www.waveshare.com/wiki/ESP32-S3-ePaper-1.54). Waveshare's examples carry no explicit licence file in the copy this was taken from; they are published for use with their hardware. If you are a Waveshare representative and would like this handled differently, please open an issue.
- `slant/dickinson_data.h` - quotations from Emily Dickinson (died 1886), public domain.
- The Oblique Strategies mode contains original prompts written in the spirit of Brian Eno and Peter Schmidt's deck. It does not reproduce that deck.
